## 🌟 Project Overview

**MiniBank Management System** is a Java-based banking application developed to demonstrate core Object-Oriented Programming concepts and advanced Java features.

The system provides banking operations such as account creation, deposits, withdrawals, fund transfers, transaction processing, and report generation.

---

## ✨ Key Features

- 🏦 **Account Management** — Create and manage different bank accounts.
- 💰 **Deposit & Withdrawal** — Perform basic banking transactions.
- 🔄 **Fund Transfer** — Transfer funds between accounts.
- 📊 **Report Generation** — Generate banking reports and statements.
- 🧾 **Transaction Logging** — Maintain transaction records.
- 🔐 **Input Validation** — Validate user inputs using custom validators and annotations.
- ⚠️ **Exception Handling** — Handle banking errors using custom exceptions.
- ⚡ **Multithreading** — Process transactions using threads.
- 💾 **File Handling** — Store and manage banking data.
- 🧩 **OOP Concepts** — Implement inheritance, abstraction, encapsulation, and polymorphism.

## ▶️ How to Run

### 1️⃣ Compile the Java Source Files

Open PowerShell inside the `Miniproject` directory:

```powershell
javac -d out (Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
```

### 2️⃣ Run the Application

```powershell
java -cp out service.MiniBank
```
